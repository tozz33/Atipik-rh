# Logos Atipik RH

Ce dossier contient les logos principaux du site.

## Fichiers attendus

- `atipik-logo.svg` (vectoriel principal)
- `atipik-logo.png` (PNG HD fond transparent, recommande 1200 px de large minimum)
- `atipik-logo-white.svg` (version blanche pour fond sombre)
- `atipik-logo-white.png` (PNG HD blanc, fond transparent)
- `favicon.png` (favicon PNG fallback)

## Etat actuel

- SVG placeholders presents pour permettre le rendu immediat.
- `atipik-logo-white.png` : copie provisoire de `atipik-logo.png` (a remplacer par l'export blanc officiel).

## Recommandations export

- Format PNG: fond transparent, profil sRGB.
- Taille minimale: 1200 px de large pour limiter la pixellisation.
- Ne pas compresser de maniere destructive.
