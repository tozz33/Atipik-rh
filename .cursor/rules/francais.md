## Règle de langue (projet)

Toutes les sorties de Cursor/IA doivent être en **français** :

- Réponses de chat
- Prompts/commandes `.cursor/commands/*`
- Textes de pages, contenus MDX/JS, micro-copies UI
- Commentaires ajoutés dans le code (si nécessaires)

Exception : ne pas traduire les identifiants techniques (noms de fichiers, variables, fonctions, API, libs).
